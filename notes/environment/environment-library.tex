------------------------------------

The Environment Library bridges the gap between *input geographical data* and *simulation of mosquito populations*. The Environment Library defines three important entities:

* [[The Mesh Object]], the graph of nodes and edges
	* [[The Environment Object]], a mesh together with its per-node data and time series
	* [[The Environment File]], a file format used to represent an Environment Object on disk, and therefore allow environments to be stored between simulation runs.
