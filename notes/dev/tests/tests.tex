A rigorous testing protocol is required to ensure that the code functions as expected: it would be pretty embarrassing to make some scientific claims (or design a trial!) and later discover it was based on a bug in the simulation code.

We define two different classes of test:

* [[Unit Tests]] which check if the individual components of the code produce expected results
	* [[Regression Tests]] which check the output of the full code against a known `oracle', and highligh differences between the two.
